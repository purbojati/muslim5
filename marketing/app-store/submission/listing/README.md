## Accuracy note for the title

“Lock Screen” is included in the App Store name as requested. The app does not replace or lock the iOS system Lock Screen. Salah Focus uses Apple Screen Time APIs to show an app-blocking shield over ordinary apps. The description and review notes state this distinction explicitly.
